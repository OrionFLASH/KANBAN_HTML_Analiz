**Версия документа:** 3.0.0 (2026-09-10). Обзорный гайд: [CONFIG_EXCEL_V2.md](CONFIG_EXCEL_V2.md).

Регенерация: `python3 scripts/gen_config_excel_v2_params.py` (в репозитории — этот генератор).
